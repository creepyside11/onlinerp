# Ключ подписи

`release.p12` — постоянный ключ, которым подписывается каждый APK.
`release.p12.b64` — его копия в base64, именно её берёт CI.

## Зачем он в репозитории

Android ставит обновление поверх установленной версии только тогда, когда
подпись совпадает. Если ключ генерировать заново на каждой сборке, каждая
установка превращается в «приложение не установлено: конфликт с другим
пакетом», а старую версию приходится удалять вручную.

Раньше CI так и делал — генерировал новый ключ при каждом запуске. Отсюда
и была ошибка при установке.

## Параметры

| Что | Значение |
|---|---|
| формат | PKCS#12 |
| алиас | `rakcrmp` |
| пароль | `rakcrmp` |
| SHA-256 сертификата | `c850cacd2a1938bddb7c6eca412013dcd2fdcda3a87b3ed398d52c41b44eab1d` |
| действует до | 2056-11-14 |

Сборка сверяет отпечаток с этим значением и падает, если он изменился.

## Сменить ключ

Только осознанно: после смены установленные копии придётся удалять.

```bash
python3 build/make_keystore.py --out keys/release.p12 --password rakcrmp
base64 -w0 keys/release.p12 > keys/release.p12.b64
python3 build/make_keystore.py --out /tmp/x.p12   # посмотреть новый SHA-256
```

Затем обновить `EXPECTED` в `.github/workflows/build.yml` и отпечаток в
этой таблице.

## Оговорка

Репозиторий публичный, значит ключ доступен всем. Для мода к игре это
приемлемо: ключ нужен только для непрерывности обновлений. Но если
собирать что-то более чувствительное — ключ должен лежать в секретах
репозитория, а не здесь.
